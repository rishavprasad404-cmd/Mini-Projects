### ✨ About
This repository contains small Python mini-projects built for learning and practice. Each project is self-contained, easy to run, and perfect for beginners to strengthen Python fundamentals like loops, conditionals, and input/output.

### 🚀 Features
- Beginner-friendly & well commented code
- Clean structure — each project in its own folder
- Interactive command-line applications
- Great for learning Python basics

### 📦 Projects Overview

| Day | Project | Description | Status |
|-----|---------|-------------|--------|
| Day 7 | Student Marks Calculator | Calculate total, average, grade from marks | ✅ |
| Day 7 | Personal Profile Generator | Generate a formatted personal profile | ✅ |
| Day 14 | ATM System | Simple ATM with balance check, deposit, withdraw | ✅ |
| Day 14 | Multiplication Table | Generate multiplication table for any number | ✅ |
| Day 24 | Smart Shopping Cart System | Manage Shopping Cart using List - Add, Insert, Remove, Count Slicing Sort & Copy | ✅ |
| Day 24 | Student Result System using Nested Lists | Store the Marks in a Nested List print matrix, find student & subject marks, find highest marks | ✅ |
| Day 28 | A Delivery Application to store coordinates using Tuple | Store the coordinates in  a Tuple, Use Tuple Unpacking to store these coordinates  into two separate variable and print its output | ✅ |
| Day 28 | Online Learning Platform using Sets | Store students of Python & Cyber Security in Sets, find common, only Python, only Cyber Security & all students using intersection, difference & union | ✅ |
